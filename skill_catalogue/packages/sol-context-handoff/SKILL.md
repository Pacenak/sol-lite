## When to Use

Preserve grounded requirements, decisions and tool evidence across sessions or fleet handoffs.

## Procedure

1. Read the current task and execution evidence. Record objective, requirement IDs, approved decisions, modified files, checks and exact unresolved failures.
2. Separate facts from assumptions; link to source paths and revisions. Summarize only inspected material, preserving uncertainty and denied operations.
3. For skill-pack transfer compare the actual manifest and content hashes; stage untrusted incoming content and report conflicts. Do not claim remote activation from a successful local export.
4. Write the handoff with a concrete next action. Verify every named file and result, and preserve local edits and owner/sector boundaries.

## Pitfalls

Skills do not grant permissions or tool access. Report missing prerequisites and failed checks; never manufacture execution evidence.

## Verification

Map each claimed outcome to an observed result. Read [the acceptance rubric](references/acceptance.md) when validating this procedure.
