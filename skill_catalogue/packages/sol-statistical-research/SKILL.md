## When to Use

Analyze supplied research data with explicit sampling assumptions and reproducible uncertainty estimates.

## Procedure

1. Define the estimand, units, sampling design and prespecified comparison before examining outcomes. Preserve input data and record provenance.
2. Inspect missingness, sample sizes, distributions and dependence. Report design limitations; do not let a diagnostic p-value automatically choose the analysis.
3. Check installed package versions. Calculate effect estimates and uncertainty with reproducible code, fixed random seeds when applicable, and a justified multiplicity policy.
4. Distinguish exploration, simulation and measured evidence. Save code and exact outputs; a numerical result does not establish causality or replication.

## Pitfalls

Skills do not grant permissions or tool access. Report missing prerequisites and failed checks; never manufacture execution evidence.

## Verification

Map each claimed outcome to an observed result. Read [the acceptance rubric](references/acceptance.md) when validating this procedure.
