# Configuration

Configuration is stored in `config/`:

- `sol-lite.yaml` — runtime, workspace, skills and platform settings.
- `permissions.yaml` — operation permissions.
- `agents.yaml` — agents and delegation.
- `models.yaml` — provider and profiles.
- `schedules.yaml` — schedule configuration.
- `logging.yaml` — logging configuration.

Environment variables can override selected runtime roots and the Ollama endpoint.
