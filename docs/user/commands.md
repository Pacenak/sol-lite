# Commands

For step-by-step explanations and examples, read the [complete beginner user guide](beginner-user-guide.md).

| Command | Function |
|---|---|
| `/help` | command reference |
| `/settings` | open user preferences |
| `/follow <path>` | dry inspection of a workspace-relative procedure manual |
| `/agents` | list agents |
| `/use <agent>` | select agent |
| `/new` | new session/workspace |
| `/workspace` | show current workspace |
| `/workspaces` | list registered workspaces |
| `/sessions` | list sessions |
| `/skills ...` | skill management |
| `/background <prompt>` | start concurrent task |
| `/tasks` | list background tasks |
| `/tasks cancel <id>` | cancel queued task |
| `/status` | current agent status |
| `/verbose` | expanded activity |
| `/debug` | debug display |
| `/normal` | normal display |
| `/tools` | tool inventory |
| `/doctor` | Ollama, Jira, and voice diagnostics |
| `/listen` | record speech and send it as your message |
| `/speak` | turn spoken replies on or off |
| `/flare [on\|off]` | session character manner; off when you start, kept across `/new`, gone when you quit |
| `/quit` | exit |


For the complete beginner copy/paste command sheet, see [Dummies Command List](dummies-command-list.md).

Shell-level commands (`sol-lite doctor`, `connect`, `google-connect`, …) are in [CLI reference](cli-reference.md). Environment variables and YAML layers are in [Configuration](../architecture/configuration.md).

Studio manuals, host environment, secrets, and file backups are in [Studio change gate](studio-change.md).
