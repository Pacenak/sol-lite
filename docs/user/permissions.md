# Permissions

Permissions are operation-scoped. Examples:

- `filesystem.read`
- `filesystem.write`
- `terminal.read`
- `terminal.write`
- `network`
- `skills.inspect`
- `skills.install`
- `repository.read`
- `repository.write`
- `repository.remote`

The policy is in `config/permissions.yaml`. A skill does not alter these permissions.
