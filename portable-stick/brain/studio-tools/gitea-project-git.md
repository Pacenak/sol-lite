# Gitea + project git (when using a studio host)

Carry-mode Lite is for personal helper work. For Cursor-class project git on Outpost:

1. On the **studio host**, open Outpost chat → Context → **Use as git project** (Outpost path or paired PC folder).
2. Prefer `git_project_*` tools; **push/merge require Yes**. Never auto-push.
3. Live host product trees: `sol-git-upgrade` — never wipe `data/`, never force-push `main`.
4. Auth stays HUMAN-OPS (`SOL_GITEA_TOKEN` / Credential Manager on that machine).

Stick `data/` can hold notes about which hosts/repos you use; keep tokens off the stick README.
