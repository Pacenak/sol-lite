How sol-lite works
SOL-Lite is a cross-platform, local-first multi-agent engineering assistant. Users enter through the CLI and terminal, select an agent and session workspace, then receive work performed through native Ollama tool calls, with evidence-based results and approval gates for mutations. The graph also preserves documented skills, background tasks, artifacts, integrations, voice, and remote execution. Some subsystem links rely on README descriptions because their runtime wiring was not sampled.
