# Book to Skill

## Procedure
Use a user-supplied or legally accessible source. Extract concepts into original procedural guidance, cite the source, preserve attribution, and avoid reproducing long protected passages. Define triggers, procedure, failure modes, and validation.


## SOL-Lite boundary
This skill provides reasoning guidance only. It does not grant filesystem, terminal, repository, network, skill-install, or application permissions. Runtime policy and explicit approvals remain authoritative.
