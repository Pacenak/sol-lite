# Spreadsheet reporting

Use native artifact tools. Name sheets descriptively, place headers in the first
row, keep data types consistent, and distinguish inputs from calculations in
labels. Use formulas for derived totals and native charts for comparisons.
Provide chart ranges including the header row. Do not include external workbook
links, active network formulas or macros. Check formulas against independently
computed expected values; cached values alone do not establish correctness.
Inspect rendered print areas for clipped columns and unreadable labels when
preview inspection is available. Report recalculation and visual review limits.
Skills do not grant permissions.
