# Systematic Debugging

Reproduce the failure before changing code. Record observed evidence. Separate verified facts from inference. Isolate the root cause before implementing a fix. After the fix, repeat the original reproduction and run focused and regression tests. Never call a quick workaround a root-cause fix.
