# Presentation design

Use native artifact tools with widescreen slides. Give each slide one supported
message and a descriptive title. Use short bullets, at most six per slide, with
detail in speaker notes. Split dense content into multiple slides. Match the
shared business theme and keep slide text editable. Render and inspect every
slide for clipping, overflow, contrast and readable spacing when inspection is
available. Never equate a valid PPTX package with visual approval. No Microsoft
Office dependency is required; skills do not grant permissions.
