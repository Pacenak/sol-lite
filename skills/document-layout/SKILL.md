# Document layout

Use artifact_dependencies and artifact_create. Default to A4, generous margins,
11-point body text, clear heading hierarchy, white backgrounds and restrained blue
accents. Lead with purpose and conclusion. Keep tables rectangular, concise and
readable; split wide tables rather than reducing text to an unreadable size.
Use artifact_render for PDFs and page previews. Inspect every page for clipping,
broken tables, orphan headings and spacing when visual inspection is available.
Revise content and re-render on defects. Report missing renderers and unperformed
visual review explicitly. Skills do not grant permissions.
