# Documentation Engineering

Verify commands and paths against the actual repository.

Lead with the purpose, intended reader and supported conclusion. Separate facts,
assumptions and recommendations. Use descriptive headings and source citations
for external claims. Choose editable DOCX for formal reports, Markdown for repo
documentation, and PDF for distribution. Route designed exports through native
artifact tools and document-layout guidance. Do not invent evidence or claim
rendering or visual inspection that did not occur.
