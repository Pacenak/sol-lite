# Debugging Methodology

## Procedure
Use this sequence: reproduce → observe → isolate → instrument → hypothesize → falsify → fix → validate → regression test.

Never replace missing evidence with assumptions. Prefer a failing test, log, trace, or direct reproduction over model intuition.
