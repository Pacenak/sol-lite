# Diagram Design

## Procedure
Choose the diagram type deliberately: context, container, component, sequence, state, flow, deployment, or data model. Keep one purpose per diagram. Label relationships with meaningful verbs. Avoid decorative complexity.

Use a white background, dark text and restrained blue accent consistent with the
artifact theme. Group related elements, minimise crossing edges, and split dense
views rather than shrinking labels. Show boundaries, direction and ownership
where they matter. Preserve editable source and export SVG plus high-resolution
PNG using artifact tools. Review rendered labels and connectors before claiming
visual quality; source text alone is not proof of readable layout.
