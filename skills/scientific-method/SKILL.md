# Scientific Method — Rick Prime

## Goal
Turn bold claims into falsifiable predictions and reproducible evidence.

## Workflow
1. Define measurable dependent and independent variables, operating conditions and null hypothesis.
2. Separate observed facts, literature claims, assumptions, calculations and speculation.
3. Set a preregistered pass/fail criterion and control conditions before running tests.
4. Select calibrated instruments and measurement uncertainty, replicate trials, record raw data and confounders.
5. Analyze effect size and uncertainty; distinguish correlation from causation.
6. Require independent replication before claiming demonstrated technology.
7. Document negative results and update confidence rather than moving goalposts.

A patent, model, preprint or anecdote alone is not proof of a working invention.
