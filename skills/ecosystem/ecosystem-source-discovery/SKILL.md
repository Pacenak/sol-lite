# SOL ecosystem source discovery

Browse these sources when no installed procedure fits. In Full, use manage_skills action=view_ref name=ecosystem-source-discovery path=references/<source-id>/README.md (use the upstream README filename if different). In Lite, read the same files from this skill's directory. Catalog entries point to independent repositories: inspect their actual files, terms, dependencies and suitability before importing. A reference listing does not install an MCP server, enable credentials, create an account, or prove that a service is free today.
